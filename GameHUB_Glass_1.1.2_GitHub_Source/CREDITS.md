## GameHUB Glass changes

The project adds or substantially replaces the fullscreen presentation, bounded multi-view renderer, Home shelves, local search and collections, game manager, Steam import, settings and diagnostics, prepared artwork pipeline, release isolation, regression tests, and optional local Hero video/logo support.

These changes were prepared for the GameHUB Glass project with OpenAI-assisted implementation and review. Human maintainers remain responsible for testing, publication, licensing compliance, and project decisions.

## Platforms and tools

- [Rainmeter](https://www.rainmeter.net/) provides the skin runtime.
- Windows PowerShell 5.1, Windows Forms, WPF, and .NET Framework provide the local manager and optional media helper.
- Steam names and URI handlers are used only for optional local discovery and launching.

No Rainmeter plugin binaries, external fonts, game executables, game art, or preview videos are bundled in the public clean package.
