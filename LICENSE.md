## Modification notice

GameHUB Glass substantially changes the interface and implementation. Major additions include a bounded multi-view launcher, Home shelves, local search and collections, a Windows Forms manager, Steam import, artwork preparation and framing, diagnostics, deterministic release tooling, regression tests, and optional local Hero video/logo support. Development included OpenAI-assisted implementation and review.

See `CHANGELOG.md` and `RELEASE.md` for the version history and current changes.
